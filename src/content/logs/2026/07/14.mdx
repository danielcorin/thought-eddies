I've been building and running several homebrewed personal agents since late 2025. By this I mean software like Nous Research's Hermes or the OpenAI supported OpenClaw, which have exploded in popularity this year.

I used to use personal messaging apps to interact with my agents away from my computer. Managing context and multiple projects quickly became impossible, and I ended up with more chats than I could handle.

I tried enterprise messaging apps, but they lack the UI primitives to track what each agent is up to and its trajectory. You can't see if they're doing the right work in response to your prompt.

I built Threads for myself to solve this problem. I send off work to my agents wherever, whenever. Mostly from my phone.

I'm sharing it in hopes it will help solve similar problems for you. Create a workspace and prompt your agent to wire itself in, then start chatting.

Let me know how it goes!

https://threads.space/
